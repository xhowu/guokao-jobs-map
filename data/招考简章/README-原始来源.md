## 表格结构

各年度表格列结构基本一致，主要包括：

- **职位信息**：部门代码、部门名称、用人司局、机构性质、招考职位、职位属性、职位分布、职位简介、职位代码、机构层级、考试类别
- **招录规模**：招考人数
- **资格条件**：专业、学历、学位、政治面貌、基层工作最低年限、服务基层项目工作经历
- **其他**：是否组织专业能力测试、面试人员比例、工作地点、落户地点、备注、部门网站、咨询电话

> 提示：用 Excel/WPS 打开后，可通过「数据 → 筛选」按专业、学历、政治面貌、工作地点等条件筛选岗位。
