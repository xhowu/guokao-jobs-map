# 国考岗位地图（2019–2027）

把 2019–2027 共 9 个年度国家公务员考试（中央机关及其直属机构考试录用公务员）的**招考简章**与**进面分数线**，整理成一个可以在地图上探索的自包含网页。

- **150,976** 个岗位 · **22,368** 个用人单位 · **5,382** 个工作地点 · **100** 个专业大类
- 网页是**单文件自包含 HTML**（约 10 MB），下载后双击即可打开，不需要服务器、不需要联网、不依赖任何外部 CDN

## 网页能做什么

| 功能 | 说明 |
|---|---|
| 地图探索 | 省 / 市 / 区县 / 单位 / 岗位五级聚合，圆点越大越红代表岗位越多 |
| 多维筛选 | 学历、学位、政治面貌、基层工作年限、性别、服务基层项目、面试比例、招考人数…… |
| 备注派生条件 | 限应届 / 限 27 届、英语四六级与专四专八、限户籍 / 生源地、资格证书、备注工作年限 |

| 历年分数 | 本岗位历年进面分数线折线图；跨年度按报考条件匹配「基本同岗」，两者不一致的年份以浅色点标出「同单位类岗」 |
| 分数点详情 | 悬浮查看该年度岗位的招考职位 / 职位简介 / 专业 / 学历 / 学位 / 政治面貌 / 基层年限 / 备注；点击可钉成对比卡片（可拖动、可关闭） |
| 导出 | 单个岗位或整个筛选结果导出 CSV |

## 脱敏声明

官方发布的「面试人员名单」包含每位进面考生的**姓名**与**准考证号**，属于个人信息。

**本仓库不存储任何考生个人身份信息。** 入库前的处理方式：

1. 用 `scripts/desensitize.py` 删除 `姓名`、`准考证号` 两列；
2. 保留对研究有用的字段：`招录机关`、`部门代码`、`用人司局`、`招考职位`、`职位代码`、`最低面试分数`；
3. 用 `scripts/verify_no_pii.py` 全文扫描，确认输出文件中不再存在 13–16 位纯数字（准考证号特征）与「姓名」列。

复现方式：

```bash
python scripts/desensitize.py  <原始名单目录>  data/面试人员名单-已脱敏
python scripts/verify_no_pii.py <原始名单目录>  data/面试人员名单-已脱敏
```

## 数据说明与口径

- **唯一键**是 `年度 + 部门代码 + 职位代码`。单独用职位代码不唯一（同一年内就有 18,040 组重复），且职位代码会被单位回收复用（跨年复用 10,707 个），所以跨年度关联不能靠代码，只能用「名称同类型 + 报考条件一致」推断。
- **分数覆盖**：2019–2026 各年度约 97.6%–98.9% 的岗位有进面分数线；**2027 年度面试尚未进行，故为 0%**，网页中已按「暂无数据」处理而不是当作 0 分。
- **`最低面试分数`** 指该职位进面考生的最低分（即通常说的进面分数线），不是录用分、不是总成绩。
- 一个工作地点可能对应多达 1,043 个单位，因此地图做了点位聚合，避免重叠。
- 跨年度「同岗」是推断结果：同单位内、名称属同一类型（忽略尾部括号编号）、学历 / 学位 / 政治面貌 / 基层工作最低年限 / 服务基层项目工作经历一致且专业要求有交集，标为**基本同岗**；条件不完全满足的标为**同单位类岗**，仅供参考。

原始数据来自国家公务员局及各招录机关公开发布的招考简章与面试人员名单，版权归原发布方所有。本仓库仅做格式整理与可视化，不对数据准确性做担保，**不作为报考依据**，请以官方发布内容为准。
